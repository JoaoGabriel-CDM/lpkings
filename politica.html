Política de Privacidade

1. Coleta de Dados

Coletamos apenas os dados fornecidos voluntariamente através dos formulários de contato (nome, e-mail, telefone e nome da empresa) para fins de atendimento e envio de propostas comerciais.

2. Uso das Informações

Os dados coletados são utilizados exclusivamente para a prestação dos serviços contratados, suporte técnico e comunicações diretas entre a FlyNode e o cliente.

3. Compartilhamento de Dados

A FlyNode não vende, aluga ou compartilha dados pessoais de clientes com terceiros para fins publicitários. Dados só serão compartilhados quando estritamente necessários para a execução de integrações contratadas pelo cliente (ex: ferramentas de CRM ou e-mail marketing).

4. Segurança

Adotamos medidas técnicas de segurança para proteger as informações armazenadas contra acessos não autorizados, alterações ou destruição.

5. Direitos do Usuário

O usuário pode solicitar a exclusão ou alteração de seus dados de nossa base a qualquer momento entrando em contato pelo canal de suporte oficial.
